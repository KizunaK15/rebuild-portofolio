## Overview

The Post Stroke Smart Hand Gloves help stroke patients regain hand mobility through guided, data-tracked therapy sessions. Unlike off-the-shelf devices, this system gives therapists real-time visibility into every session via cloud sync and WhatsApp notifications.

## Technical Approach

Flex sensors detect finger extension angles and feed data into a PID servo controller achieving 95% motion accuracy. An LVGL-driven touchscreen displays the current exercise regime, progress, and session history directly on the device.

## Results

- Silver Medal at IIIEX 2025 international invention exhibition
- 80% reduction in therapist manual reporting time
- Stable operation across 200+ test sessions without hardware failure
