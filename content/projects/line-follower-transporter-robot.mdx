Line follower transporter robot adalah robot otonom yang dirancang untuk mengikuti garis dengan precisi sambil mengangkut muetan dari satu titik ke titik lain. Robot ini menggunakan array sensor inframerah untuk mendeteksi posisi garis dan mikrokontroler ESP32 untuk mengendalikan kecepatan motor berdasarkan algoritma PID.

Sistem kontrol dirancang agar robot dapat tetap berada pada garis bahkan ketika terjadi perubahan kondisi superficie atau beban yang berbeda. Dengan integrasi antara sensor, algoritma kontrol, dan aktuator, robot ini mampu melakukan tugas transporte Secara otonom tanpa intervensi manusia.
