## Overview

Manual door access on campus buildings creates security gaps and provides no audit trail. This project implemented an RFID-based gate using an STM32 microcontroller that validates card UIDs and logs all access events to an SD card.

## Technical Approach

The RC522 RFID reader communicates via SPI. Validated UIDs are checked against a hard-coded allowlist in flash memory. Authorized entries trigger the servo motor to open the gate for 3 seconds, while all events — authorized and rejected — are appended to a timestamped CSV log on the SD card.

## Results

- Read latency consistently under 200 ms across 500 test events
- Zero missed gate operations during the evaluation period
- CSV log integrity verified against all 500 access events
